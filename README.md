# Money Save




Money Save is a weekly money tracker Android app. It is made for delivery partners and anyone who earns week by week — track income, expenses, Blinkit pay, and borrowed money, all on your phone.




## Download the latest version (APK)




Get the latest APK from the Releases page:




https://github.com/rejaul070/money-save/releases/latest




Tap the MoneySave-vX.Y.apk file under Assets to download it, then tap the downloaded file to install it. Install over the old version — never uninstall first, or your saved data will be deleted.




Current version: v6.0




## Features




- Weekly money tracking (Week / Month views) with a plan for home, other spending and daily spending
- Blinkit pay tracking — current week's Blinkit pay stays separate with a Waiting badge until it settles Sunday night
- Borrowed Money (udhaar) — loans with due date, return time, countdown and reminders
- Home-screen widgets and app shortcuts
- Works fully offline — all your money data stays only on your phone, nothing is uploaded
- English and Bengali, light and dark mode
